# B. Forms that read as machine-written

`tools/check_style.py` flags most of them. A flag is a question, not a verdict (C7).

| ID | Form | Do instead | Source |
|---|---|---|---|
| B1 | Em-dashes (—, `---`) | A comma, a full stop or parentheses | user |
| B2 | "rather than" | "instead of" | user |
| B3 | "X, not Y" antitheses ("skills to acquire, not products to deliver") | At most one per document, where it carries a decision; elsewhere a plain statement | user |
| B4 | Reflexive hedging with "may" ("an account may no longer correspond") and uniform hedging | State what was observed, or present cases as examples ("Three typical cases illustrate this"). Hedging calibrated to the evidence stays (B5) | user |
| B5 | Overclaiming in a conclusion | A claim as strong as its evidence, no stronger; academic genres expect calibrated conclusions | school |
| B6 | "Therefore" closing every point | Keep it where the consequence is not obvious from the order; let the order carry the others | user |
| B7 | A paragraph or section ending on a maxim or a summary of itself ("The pair we can verify best is also the largest") | End on the fact, or delete the line. Glossary entries too | user |
| B8 | Aphoristic bold lead-ins ("An address never proves a company") | A plain statement ("An address is not sufficient to identify a company") or a noun phrase (T1) | review |
| B9 | A slogan: a general moral with no agent ("Process is real, and it is there for a reason") | Delete it. Not every short sentence is a slogan: one that states a decision with a real actor stays | user |
| B10 | Tricolons everywhere ("faster, cheaper and more reliable") | One is fine, four in a section is a tell. Content lists taken from the source are exempt | review |
| B11 | Ordinals in a synthesis ("The first… The second… The third…") | Ordinary successive sentences | user |
| B12 | Openers: "It is worth noting", "Notably", "Importantly", "In today's world", "plays a crucial role" | Delete them | review |
| B13 | *leverage, delve, robust, seamless, comprehensive, showcase, underscore, highlight, serves as a, holistic* | A plain word | review |
| B14 | Clefts ("it is X that…", "what matters is…"), "there is/are", "by -ing" openers, "not only" | A direct statement | exp |
| B15 | Vague intensifiers (*key, critical, significant, essential, vital, powerful*) | A precise word or a number | exp |
| B16 | Nominalisations (*the fact that, the use of, the ability to, in terms of, with respect to*) | The verb | exp |
| B17 | `, -ing` adjuncts ("…, allowing the model to…") | A second clause with its own subject | exp |
| B18 | Bare "This is / This shows" openers | Name what "this" is | exp |
| B19 | A formula the author flagged, merely reworded | Change the idea, and grep for every variant | user |
| B20 | Dates and commit counts as narrative in a report whose period is on the cover | Leave them out. Dates that are content (a law's start date) stay | user |
| B21 | Questions or narration as titles | A noun phrase (T1) | user |
| B22 | In academic English genres: contractions, "I think", "lots of", rhetorical questions, "etc." | Full forms, an impersonal claim, "many", a statement, a complete list or "such as" | school |
