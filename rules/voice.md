# W. Voice, subjects, tense and order

- **W1. Use the active voice.** Passive voice was the author's most frequent complaint ("trash"). Give each sentence an agent and a verb it performs: "A Python pipeline processed all live accounts. It rebuilt the identifier and computed the tax number", not "the identifier was rebuilt, the tax number was computed". Avoid runs of passive clauses and the same construction three times in a row. (user)
- **W2. The subject is the thing that really acts.** An address does not "host" companies; the register lists them. A table cell needs a real actor too: "a 27-call probe showed that the setting cost twice as much for no gain, so we dropped it", not "a probe dropped the setting". (user)
- **W3. Give a narrative sentence its owner.** "Our initial assumption was that…", not "The initial assumption was that…", in a profile that narrates in the first person. (user)
- **W4. One voice per document, set by the profile, and one way of naming the author.** "We" in a report, "I" in a reflection, impersonal in a summary; never a mix with "the author" and "mine". (user)
- **W5. Do not open sentence after sentence with the same subject.** "We…, We…, We…" or "The lecture…, The lecture…" is a pattern no human writes. Alternate the subject: the system, the model, the department, a gerund, an occasional passive. (user)
- **W6. Present tense for how a system or method works, past for what was done once and what was found.** (user)
- **W7. State the action first, then its effect.** "Another measure was to group the related records that the script repeated under every entry. Removing this redundancy shortened each batch by two thirds", not the result first and the action last. (user)
- **W8. Introduce a set before judging its members.** "We tested three compression tools: A, B and C. We kept A because…", not "Of the three tools tested, we kept A". (user)
- **W9. Tell the work as it happened, with its owner**, but never as a chronological diary: structure by topic, not by week. (user, school)
- **W10. One voice down a table column.** A column is read top to bottom: rewrite all of it or none. (user)
- **W11. Write the reasoning as connected sentences.** Do not post a short statement and then explain it in the next sentence; join them with a connector: "However, serendipity comes with a tradeoff, that is, …". (user)
- **W12. Point first, plain words, example in one line.** Do not stage an actor or a case before the idea ("The X case illustrates a different risk, namely…"); write "Another risk is…, as in the X case, where…". (user)
