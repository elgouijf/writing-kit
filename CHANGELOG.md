# Changelog

## 1.0.0

- First public version. Merges three pipelines: the lessons of an engineering internship report (119 lessons, a school's ID-tagged rules, a rewrite brief), the coursework rules of an exchange semester, and the explaining rules behind course books.
- 181 rules in 13 modules with a generated index, 7 document profiles, and a log of the 14 conflicts found between the sources and how each was settled.
- Four on-demand skills (`writing`, `latex-report`, `explaining`, `course-book`), a report template with a one-page variant, a course-book template with an example, and five tools.
